# ☕ Kopi Nadi

> **Kopi yang ngerti ritme harimu.**

Kopi Nadi adalah website landing page untuk brand kopi susu literan asal Indonesia. Website ini dibuat dengan tampilan sederhana, modern, dan bernuansa hangat untuk memberikan pengalaman yang nyaman bagi pengunjung.

## 🌿 Tentang Website

Website Kopi Nadi menampilkan informasi mengenai produk kopi, cerita brand, lokasi kedai, serta tombol pemesanan.

Kopi Nadi menggunakan biji kopi asli Indonesia seperti **Gayo, Toraja, dan Kintamani**. Website juga menampilkan berbagai menu kopi dengan harga dan deskripsi masing-masing.

## ✨ Fitur Website

* 🏠 **Beranda** — Menampilkan informasi utama tentang Kopi Nadi.
* ☕ **Menu** — Menampilkan menu kopi dan harga.
* 📖 **Cerita Kami** — Berisi cerita dan asal-usul Kopi Nadi.
* 📍 **Kedai** — Menampilkan lokasi kedai di beberapa kota.
* 🛒 **Pesan Sekarang** — Tombol untuk melakukan pemesanan.
* 📱 **Responsive Design** — Dapat menyesuaikan tampilan pada perangkat desktop dan mobile.
* 🍔 **Mobile Navigation** — Tersedia menu hamburger untuk pengguna smartphone.
* ✨ **Animasi** — Terdapat animasi sederhana pada ilustrasi kopi dan navigasi.
